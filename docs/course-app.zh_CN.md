# 个人课程表使用说明

程序基于官方版本 `25add0044cb3e8ce2319c258ae96551f0ffcc2df` 的硬件驱动，
开机直接进入重新设计的每日课程表。ICS 中每一次上课均按原日期导入，UTC 时间
转为北京时间；课名、教室、教师与节次离线保存。不擅自调整节假日课程。
含有未展开循环规则的 ICS 会明确报错，不会静默漏课。

## 按键

- 上下短按：选择课程。确定：查看详情或返回。
- 长按上下：前一天／后一天。长按确定：工具菜单／返回课程。
- 菜单可回到今天、切换日期、手动校时、联网校时、调节亮度、熄屏、查看说明、进入原厂程序。
- 20 秒无操作降低亮度，45 秒熄屏；按任意键唤醒，唤醒动作不会同时触发选课。
  当前只关闭背光，CPU 保持运行；实际续航尚未测量。

完全断电后，在电脑双击 `Sync-Time.cmd` 校时，或进入菜单手动设置日期时间。
保存的时间仅用于浏览定位，每次开机均标记为待校准，不把上次关机时间当作当前时间。
可选：运行 `Configure-WiFi.cmd`，输入 2.4 GHz 无线网络，随后开机可联网校时。
无需云账号。密码只在本地输入，不写入日志；联网尝试有超时限制。

## 原厂功能保留方式

已核对这台 8 MB 设备的原始分区。原厂程序仍在 `0x10000..0x310000`，
身份卡、图片、音频等分区保持原地址，末尾为 `0x4fa000`。
仅增加 `0x4fa000..0x4fc000` 的启动选择数据，以及 `0x500000` 开始的 3 MB 课程表分区。
构建配置已将课程表烧录地址改到新分区。

安装脚本 `tools/device_boot.py --port COMx --install --build build/verified`
会核对现有分区与固件，再分段写入引导程序、分区表、课程程序和启动选择。
脚本拒绝覆盖保留的分区。**不要使用合并的 full.bin 给这台设备刷机**：
合并文件的填充区会覆盖原厂程序与数据。本项目中的合并文件仅用于构建校验。

在课程表工具菜单选择“原厂功能”并确认，即可重启进入原厂程序。
返回课程表需连接电脑，运行 `Switch-To-Courses.cmd`，工具自动查找已连接的设备。
工具只更新启动选择，随后自动校时。这是两个程序间切换，不是把原厂代码合并到课程表。
若要继续保留这种安排，请勿用其他社区固件覆盖分区布局。

## 更新课表与验证

开发环境为 ESP-IDF 5.5.3。运行 `python tools/import_timetable.py 新课表.ics`，
再运行 `tools/make_course_fonts.py --node NODE --converter LV_FONT_CONV_JS`
重新生成字库。Windows 下 `tools/build-course.ps1` 执行独立配置构建、合并校验、固件归档。
官方 POSIX 检查入口是 `tools/validate.sh`；Windows 缺少符号链接权限时部分上游测试会失败，
这些结果必须与课程表自身测试分开报告。

课表、设备日志、截图等存放于 Git 忽略的 `private/`，生成的课程数据和字体子集也已排除。
固件和设备数据可能包含个人信息，请勿公开上传。公开仓库只包含虚构课表示例。

真机验收包括字体覆盖、日期／详情／菜单、手动校时、空课日、熄屏唤醒、可选联网与原厂切换。
`tools/capture_course.py` 可获取设备实际 LVGL 渲染结果，供检查排版，但不能代替
实体屏幕色彩和物理按键的观察。
