# Fictional calendar templates

| File | Purpose |
| --- | --- |
| [timetable.csv](timetable.csv) | Editable UTF-8 table: date, start, end, name, location and description; one occurrence per row. |
| [timetable.ics](timetable.ics) | Equivalent fictional calendar for trying import and checking conversion output. |

All entries are fictional. Copy a template to `private/` before entering real courses. The EXE can also save a CSV template. Do not replace the tracked examples with your own calendar.
