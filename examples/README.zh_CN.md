# 虚构课表模板

| 文件 | 作用 |
| --- | --- |
| [timetable.csv](timetable.csv) | 可用表格软件编辑的 UTF-8 模板：日期、开始时间、结束时间、课程名、地点和备注，每行代表一次课。 |
| [timetable.ics](timetable.ics) | 与 CSV 对应的虚构日历，可用于体验导入功能或检查转换结果。 |

所有课程均为虚构示例。请先把模板复制到 `private/` 再填写真实课表，或在 EXE 中点击“保存模板”。不要直接把真实课程写进 Git 跟踪的示例文件。
